Version Control

pwd | cd | mkdir | touch | open | start | rm

  • pwd = Print Working Directory
  • cd = Change Directory
  • mkdir = Make Directory
  • Touch = create a new file
  • Open = Opens file inside of VS code using | open -a /Application/ Visual\ Studio\ Code.app filename
  • Start =
  • Rm = remove
  1. git init | initializes git for VSCode and creates a .git folder
  2. git status | Will show you if you have any status changes.
    • On branch main | No commits yet | untracked files: (use "git add filename..." to include in what will be committed) Filename... listed below. Nothing added to commit but untracked files present (use "git add" to track)
  3. git add | adds file to staging area. For all files in that directory | git add . | this will add all the new files at one time.
    • run git status again
    • On branch main | No commits yet | Changes to be comitted: (use | git rm --cached "filename ..." to unstage) | new file: "filename ..."
  4. commit -m | commits file and -m is to add a message
  5. git log | will show you: commit hash (HEAD -> main) | Author: Richard Morse and email should appear. | Date: Fri May 26 14:23:10 2025 +0100 | Filename... committed.
  6. git diff "filename ..." show you versions of the file if you want to revert back to older code
  7. push -u (remote name) (branch name)Links local and remote repositories
  8. git push -u origin mainpushes new code changes to staging area
  9. git
  • git ignore | create a file in your code tree called .gitignore so that the files you list in the .gitignore file do not get pushed to github.
